Политика конфиденциальности

Информация о данных, которые может обрабатывать Discord-бот Wondering.

Последнее обновление — 23 сентября 2026
01

Общие положения

Настоящая политика описывает, какие данные может обрабатывать Wondering при использовании его функций в Discord.

Мы стараемся собирать только те данные, которые необходимы для正常ной работы соответствующих функций бота.

02

Какие данные могут обрабатываться

В зависимости от используемых функций Wondering может обрабатывать следующие данные:

  • Discord ID пользователя;
  • Discord ID сервера;
  • Discord ID каналов и ролей;
  • настройки сервера, сохранённые для работы функций бота;
  • данные, необходимые для выполнения команд.
Wondering не запрашивает у пользователей пароли Discord, токены или платёжные данные.
03

Использование данных

Получаемые данные используются исключительно для работы функций Wondering и обеспечения корректной работы бота.

Например, настройки каналов, ролей и других функций могут сохраняться для того, чтобы бот мог использовать их после перезапуска.

04

Хранение данных

Данные хранятся только в течение периода, необходимого для предоставления соответствующих функций, если иное не требуется для технических или юридических целей.

Мы принимаем разумные меры для защиты хранимой информации от несанкционированного доступа.

05

Передача третьим лицам

Мы не продаём персональные данные пользователей и не передаём их третьим лицам для рекламных целей.

Передача информации может осуществляться только в случаях, необходимых для работы сервиса, выполнения требований закона или защиты безопасности сервиса и пользователей.

06

Удаление данных

Если вы хотите удалить данные, связанные с использованием Wondering, вы можете обратиться к владельцу или администрации проекта.

После проверки запроса соответствующие данные могут быть удалены, если их дальнейшее хранение не требуется по техническим или юридическим причинам.

07

Изменения политики

Эта политика может периодически обновляться. Новая версия будет опубликована на данной странице с указанием даты последнего обновления.

08

Контакты

По вопросам, связанным с конфиденциальностью и обработкой данных, вы можете обратиться к администрации Wondering.
